# Research foundations

| Source | Engineering use |
| --- | --- |
| [Laya](https://github.com/NandhaKishorM/laya) | Local typed decision runtime and pinned checkpoint interface |
| [TypeSafe Jev](https://docs.typesafe.ai/) | Closed decisions with explicit criteria and workflow ownership |
| [Jev for Scientific Decisions](https://arxiv.org/abs/2609.24965v2) | Inspect intermediate decisions and their consequences separately |
| [ModernBERT](https://arxiv.org/abs/2412.13663) | Efficient encoder architecture behind the local model family |
| [On Calibration of Modern Neural Networks](https://arxiv.org/abs/1706.04599) | Measure the relation between predicted probabilities and correctness |
| [SelectiveNet](https://arxiv.org/abs/1901.09192) | Evaluate accepted coverage together with error; our threshold policy is not SelectiveNet training |
| [Datasheets for Datasets](https://arxiv.org/abs/1803.09010) | Record input provenance, label meaning and intended task scope |

References guide implementation decisions. They do not transfer a paper's
benchmark results to this repository or imply endorsement by its authors.
Evaluate the actual task, languages, checkpoint and input distribution separately.
